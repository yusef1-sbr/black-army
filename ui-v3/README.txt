Black Army UI V3 — drop-in installer

Copy this ui-v3 folder into ~/black-army or copy its three files there.
Recommended: put ui-v3 inside ~/black-army, then run:

python ui-v3/apply_v3.py

Then:
python -m py_compile app.py

The installer creates templates/base.html.bak-ui-v3 before changing base.html.
